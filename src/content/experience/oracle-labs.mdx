I joined Oracle Labs in Prague in 2019 as an intern and stayed as a software engineer until 2022.
Both roles were on FastR, the implementation of the R programming language on top of Truffle and
GraalVM.

## Internship (2019 – 2020)

Implemented [ALTREP](https://svn.r-project.org/R/branches/ALTREP/ALTREP.html) for FastR. ALTREP
is R's mechanism for alternative representations of vectors, and it touches the deepest parts of
the runtime.

## Software engineer (2020 – 2022)

Maintenance of FastR as a GraalVM language:

- Upgrading the supported R version to match the reference implementation.
- Implementing the patches needed to run popular R packages on FastR.
- Performance monitoring and regression hunting.
