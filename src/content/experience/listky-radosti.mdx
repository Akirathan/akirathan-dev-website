## What I built

- **E-commerce.** A Shopify store on a custom Liquid theme, with Vue.js components embedded where
  the theme needed real interactivity.
- **Internal tooling.** An inventory and plant-lifecycle tracking app (Nuxt, hosted on Hetzner),
  so that every plant in the showroom has a known history.
- **Infrastructure.** The on-premises network and a self-hosted Frigate camera system.
- **Hardware and fabrication.** A steel grid for a vertical grow system, designed and built by
  hand; 3D printing and laser engraving for in-house production.
- **Operations.** Taxes, VAT, payroll, invoicing, and expenses.

## AI agents, used pragmatically

- Custom Claude Code skills for recurring workflows such as tax, invoice, and payroll processing.
- A 3D modelling pipeline: Nano Banana and Meshy AI for the base model, Claude Code for refinement
  and CAD step generation, and final manual touches in Blender, OnShape, or Autodesk Fusion.
- Daily Claude Code use for coding, infrastructure, and admin automation.
