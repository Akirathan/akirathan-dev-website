Many years ago, I have started with Github Copilot.
Since I was declared as an open source contributor, I got the Copilot for free, so why not to use it.
At that time, it was pretty much inline code completion that generated nonsense 80% of the time.
But the rest of the time, it was still quite useful, especially for unit tests with rather repetitive code.

My friend introduced me to [Claude Code](???) few months after it was released.
My first response was a shock, just like for many other people.
I was genuinelly impressed that now, the AI can scan the entire code base and just write code instead of me.

Some devs say they miss the coding.
I don't, at least not much.
Writing code was never the biggest part of the job.
I would estimate that I was writing code for at most 20% of the time, the rest I spent with **reading the code** - either doing reviews or reading some library code.
From time to time, I satisfy my hunger for writing the code by rewriting some generated code that I don't like myself rather than re-prompting the agent.

I don't have other subscription except for Claude.
I don't see any need for it - Claude gets the job done for me pretty well.
I have experimented with hosting an open-weight `qwen` model on a spare PC that is just sitting in a bedroom.
It's results were so poor that I have dropped the experiment immediately.
Apparently 6GB of VRAM is just too low.

I don't have experience in using AI agents at scale, in a team of multiple people, just like many other organizations.
I am eager to learn more interesting patterns how to use it.

To me, AI agent is just a magical black box that just spits out some output based on the context.
I don't understand the details - too much statistical theory for my taste - and I don't want/need to understand it now, just like I don't need to understand the details of many other technologies that I use.

Nowadays, I use Claude Code for pretty much everything.
Ranging from accounting, analytics reporting, and code.
Obviously, code writing seems to be its strongest trait.

Pretty soon, I have run into organization problems - having too many tabs opened in my terminal was just too chaotic for me.
When looking for tools that could help me with that, I have encountered [Orca](???), an [ADE](???) (Agentinc Development Environment) that lets you orchestrate dozens of subagents across dozens of worktrees while still keeping a good overview of what is going on.
