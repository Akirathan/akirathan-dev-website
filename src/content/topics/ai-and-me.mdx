I use AI where it actually helps. That sentence sounds obvious, but it took real use to find out
where the line is.

- Daily coding, infrastructure, and admin automation with Claude Code.
- Custom Claude Code skills for recurring workflows: tax, invoice, and payroll processing.
- A 3D modelling pipeline for the plant business: Nano Banana and Meshy AI for the base model,
  Claude Code for refinement and CAD step generation, and manual finishing in Blender, OnShape, or
