### 3D printing

I started with [Prusa Core One L](??) and later bought [BambuLab H2S](???) as well.
To my surprise, controlling CO2 [laser engraver](???) is much simpler than controlling an average 3D printer.
Every 3D printing enthusiast will sooner or later realize that in order to unlock the potential, they have to create their own 3D models.
With all the AI tools around today, it should be pretty easy, right?
Not quite, unfortunately.
Although those various AI tools can certainly help, they still lack a lot of features.
One of my first runs out of tokens was when I was trying to convince Claude to make some 3D model *watertight* (manifold).
At the end, I had to do that myself manually in [Blender](???).
Nowadays, it seems that [Blender with MCP](???) is the way to go for many artists and enthusiasts.

When it comes to 3D models and their customizations, I think that I have tried just about every possible tool that offers a free trial.
Starting with the [CAD](???) software, I have used [Autodesk Fusion](???) for some time.
When I start using Fusion, they were just fiddling with cloud-file storing.
Running into incredibly long UI freezes.
I believe they were syncing the file with cloud on the main thread.
It took few version upgrades until they solved the issue, but it got me stop using the software.
I have ended up with [OnShape](???).

My workflow:
Depends on complexity of whatever you are trying to create.
If it is made of simple geometries, then you can create the model entirely just in a [CAD](???) software, feed it into the 3D slicer, and send it to the printer.
If you are doing something more complex, or you wish to modify some already existing 3D model, things get more complicated.
Usually, existing 3D models publish only `STL` files, no CAD files.
So you can open them only in Blender and other mesh-editing software.

Claude, for example, is great with generating quite complex geometries from scripts.
It, however, lacks when trying to mimic some natural textures.
For that, you have to use other AI tool based on image diffusion models, like [MeshyAI](???).
